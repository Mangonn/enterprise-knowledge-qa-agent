# 04 AI 使用与个人贡献

## 我的工作

我给出企业知识问答题的可靠性要求：回答必须有文档 ID、版本日期和原文依据；资料冲突时列出双方并请求确认，不能凭空选择较新的制度；资料外问题要明确说明缺口。我要求复查相似问法、上下文追问和工具失败后的动作变化。

我创建公开 GitHub 仓库并提供真实模型运行条件。我审阅代码后，向 Codex 指出“收不到验证码邮件”与原文“企业邮箱不可用”并不等同，要求收紧追问边界并重新验证真实模型路径。我通过明确的反例和验收意见推动了这次修订。

## AI 辅助范围与分工

我使用 Codex 完成检索、原文读取、冲突与引用校验、CLI、合成文档、测试和文档；DeepSeek 在运行时选择检索、读取和结束动作。Codex 负责代码修改、测试执行、真实模型复跑和 GitHub 提交。离线 Mock 只证明流程与程序约束，不证明真实模型在其他资料上的准确率。

## 验证与记录边界

Codex 在本地运行了 21 项测试、13 组离线示例和 9 组真实模型示例；追问修订后的实际输出与 Trace 见 03-evaluation.md 和 examples/。我提供问题定义、反例和复核要求。
