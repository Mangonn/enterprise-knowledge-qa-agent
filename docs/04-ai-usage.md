# 04 AI 使用与贡献记录

## 使用范围

本仓库的代码、合成资料、测试、示例生成器和文档由 Codex AI 助手在本次对话中编写、修改并在本地验证。运行时使用 DeepSeek 作为真实动作决策模型：它只调用检索、原文读取和受校验的结束动作，不生成或修改仓库代码。`MockPolicy` 是显式规则策略，不能用于证明模型 ReAct 效果。

用户提供题目、验收标准、公开 GitHub 仓库地址，以及真实模型运行条件。本次记录没有可核实的用户手工代码修改，因此不把 AI 生成代码描述为候选人独立编写。提交者如后续亲自修改，应在新提交中补充个人修改内容与验证结果。

## 修改、验证与边界

1. AI 助手实现 Unicode 归一化与别名检索、上下文主题补足、文档原文读取、带版本日期和哈希的引用。
2. AI 助手增加结束校验：未检索、未读原文或冲突未处理时拒绝回答；版本日期不自动表示制度优先级。
3. AI 助手复查时修正同主题但不同细节导致的错误回答；根据 2026-11-03 评审报告进一步收紧“收不到验证码邮件”的追问边界，更新真实模型 Trace；运行 21 项自动测试、13 组离线样例及 9 组真实模型样例；对照替换后的原文检查答案、引用和后续动作变化。详见 [`03-evaluation.md`](03-evaluation.md)。
4. 模型密钥只用于本地运行，未写入代码、示例或提交；`.env` 已在 `.gitignore` 中。真实模型结果只代表记录中的调用，Mock 结果仅用于回归。
