# 05 复盘

## 最难的问题

文档检索“命中”不等于答案有依据。只返回检索摘要容易让模型在未读原文时生成看似合理的回答；D02 日期较新也容易被误认为自动覆盖 D01。因此将搜索结果限定为元数据，要求读取原文后才能结束；输出的引用和答案直接来自读到的文本。冲突校验根据原文中的期限数字比较，未知适用范围则追问，而不是替员工选一条政策。

## 学到的做法

工具观察必须影响下一步。真实模型在资料外问题中多次换词检索，在读取超时后重读，在上下文追问中依据历史检索，并在结束被证据校验拒绝后补查。逐步 Trace 让这些决定和边界可核对。替换制度内容的测试也表明引用与答案来自当前资料，而不是预写日志。

## 下一步与未完成部分

核心验收已覆盖。尚未实现生产级全文/向量检索、文档权限、正式版本继承关系、跨主题逻辑冲突识别、人工制度审批，以及模型多次运行成功率统计。当前资料和冲突规则均为合成演示，下一步应先扩展带标注的真实问答评测集，再审查召回率、无依据回答率与冲突检出率。
